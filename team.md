## Project Overview

The Micromouse project involves designing, building, and programming an autonomous robot capable of navigating an unknown maze.

The robot will use sensors, motors, and an embedded controller to explore the maze, identify paths, and reach the target.

## Development Environment

- **Programming Language:** C
- **Simulator:** MMS (Micromouse Simulator)
- **Microcontroller:** ESP32
- **Version Control:** GitHub
- **Task Management:** Trello

## M0 – Project Kickoff

The initial project setup includes:

- Team formation and registration.
- Assignment of team roles.
- Creation of a private GitHub repository.
- Creation of a Trello project board.
- Installation and testing of the MMS simulator.
- Uploading the official starter kit.
- Preparation of the initial hardware parts list.

## Repository Structure

The repository contains the official Micromouse starter kit, including the simulator interface, example wall-following program, solver template, practice mazes, and ESP32 resources.
